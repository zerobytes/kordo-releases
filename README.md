# Kordo

Aplicativo para organizar projetos, tarefas e trabalho com agentes.

[Site oficial](https://kordo.pro) · [Releases](https://github.com/zerobytes/kordo-releases/releases)

## Download para macOS

[Baixar Kordo 1.0.1 (2)](https://github.com/zerobytes/kordo-releases/releases/download/v1.0.1-2-macos-arm64/Kordo-1.0.1-2-macos-arm64.dmg)

Requer Mac com Apple Silicon e macOS 15.0 ou posterior. O app e o DMG têm assinatura Developer ID e notarização da Apple.

Abra o DMG e arraste Kordo para Applications. Esta primeira versão inclui o atualizador: quando uma nova versão compatível estiver disponível, o botão de atualização aparecerá acima de Configurações.

SHA-256 do DMG: `c9bc05158056317f2e92522e9a7c3944b20ab2cf44bf59ddb7599c5a1ef52c26`
