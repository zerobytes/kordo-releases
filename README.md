# Kordo

Aplicativo para organizar projetos, tarefas e trabalho com agentes.

[Site oficial](https://kordo.pro) · [Releases](https://github.com/zerobytes/kordo-releases/releases)

## Download para macOS

[Baixar Kordo 1.0.2 (3)](https://github.com/zerobytes/kordo-releases/releases/download/v1.0.2-3-macos-arm64/Kordo-1.0.2-3-macos-arm64.dmg)

Requer Mac com Apple Silicon e macOS 15.0 ou posterior. O app e o DMG têm assinatura Developer ID e notarização da Apple.

Abra o DMG e arraste Kordo para Applications. O aplicativo inclui o atualizador: quando uma nova versão compatível estiver disponível, o botão de atualização aparecerá acima de Configurações.

SHA-256 do DMG: `3b2a789fc479e172a1b529cf7e74c62b93053239a2663379ada32f8d8f8dd74c`
